# Mathsboard

Mathsboard is an iPad maths, statistics, physics and "maths for AI" tutor. You write with the Apple Pencil on a whiteboard, and the app checks, explains and guides you step by step.

This repository only holds the app's public documents. The app's source code is private.

## What the app provides

- **A smart whiteboard.** Write a formula or exercise by hand. The app reads it, solves it step by step and explains every step. You can ask questions about any step.
- **Courses.** Progressive lessons in maths (algebra to linear algebra), primary school (Year 1–2), statistics, physics and maths for AI (neurons, learning, Kalman filters, transformers and reinforcement learning), in six languages.
  - Every lesson has a conceptual introduction, a worked explanation, an interactive explorer and three exercises.
  - Worked steps are computed by the app's own maths engine.
- **Exercises and hints.** Practise similar exercises. When you are stuck, "I don't know what to do" shows only the next step.
- **Applied maths.** 100 real-world cases (finance, medicine, engineering, AI…) that use the maths of each lesson.
- **Classroom mode.** A teacher and students can connect their iPads on the same local network to share live challenges, a leaderboard and recorded explanations. No internet is needed.
- **Class screen.** The board, the explanation or the lesson's introduction can be shown on an external display.
